EmulatorOS is a browser-based gaming platform that lets you play over 100 web games and classic retro console titles directly in your browser. Powered by EmulatorJS, it supports emulation of 20+ console systems — from NES and SNES to Nintendo 64, Game Boy Advance, PlayStation, and beyond. The platform works as a Progressive Web App (PWA) so you can install it for offline play and add it to your home screen.

## Get up and running

<Steps>
  <Step title="Clone or fork the repository">
    Fork `dih722721-pixel/webthings` on GitHub and clone it locally. The entire platform is static HTML/JS — no build step required.
  </Step>
  <Step title="Serve the files">
    Serve the root directory with any static file server. The platform is designed for GitHub Pages deployment but works with any HTTP server.
  </Step>
  <Step title="Add a game page">
    Create an HTML file in the root, embed an `<iframe>` pointing to your game file, and include `main.js` for the shared navbar and tab-cloaking support.
  </Step>
  <Step title="Configure EmulatorJS (for ROM-based games)">
    Set the required `window.EJS_*` global variables before loading `data/loader.js` to point the emulator at a ROM file and select the correct core.
  </Step>
</Steps>

<Note>
  EmulatorOS is deployed as a static GitHub Pages site. All game content runs entirely in the browser — there is no backend server or database.
</Note>
